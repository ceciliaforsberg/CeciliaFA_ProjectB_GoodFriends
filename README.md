# GoodFriends

ASP.NET Core Razor Pages web application with full CRUD functionality against 
a SQL Server database via Entity Framework Core.

## Tech stack
C#, ASP.NET Core, Razor Pages, Entity Framework Core, SQL Server

## What it does
- Browse friends by country and city
- View friend details including address, pets, and quotes
- Create, edit, and delete records with both frontend and server-side validation
